# Step 7 — State UI

Изменения сделаны поверх Step 6; сенсоры, база личной нормы, визуальный поток и валидатор глаз сохранены.

## Пользовательский интерфейс
- Главный экран сокращён до трёх смысловых блоков: состояние, основание, рекомендация.
- Большое постоянное видео убрано. Камера открывается отдельным диагностическим превью только по запросу.
- Технические данные перенесены в раскрывающуюся панель с четырьмя вкладками.
- В подробностях выводятся более 50 сырых и производных параметров текущей сессии.

## Самооценка
- Усталость: Samn–Perelli 1–7.
- Сонливость: KSS 1–9.
- Каждый шаг имеет отдельную пользовательскую формулировку.
- Под выбранным значением показываются соседние уровни, чтобы было проще провести границу.
- Старые SQLite-базы мигрируют без удаления предыдущих самооценок.

## Итоговый уровень
- Ровно 5 функциональных уровней наблюдаемой рабочей нагрузки.
- Надёжность измерений вынесена в отдельную характеристику.
- Добавлен гистерезис: уровень не должен прыгать из-за одиночного окна измерений.
- Крайняя самооценка может повысить уровень немедленно.
- Глазной канал по-прежнему диагностический до завершения размеченной валидации.
