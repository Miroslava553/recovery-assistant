STEP 7 — ПОЛЬЗОВАТЕЛЬСКОЕ СОСТОЯНИЕ + САМООЦЕНКА

1) Открой PowerShell в этой папке.
2) Демо-режим:
   python assistant_app.py --demo

3) Реальный режим:
   python assistant_app.py

Что проверяем в Step 7:
- главный экран содержит три смысловых блока: СОСТОЯНИЕ / ОСНОВАНИЕ / РЕКОМЕНДАЦИЯ;
- пользовательский итог имеет 5 функциональных уровней нагрузки;
- качество данных показывается отдельно и не считается шестым уровнем;
- «Как я себя чувствую» открывает два ползунка:
  Samn–Perelli 1–7 и KSS 1–9;
- у каждого значения есть отдельная понятная подпись и сравнение с соседними уровнями;
- камера скрыта по умолчанию и открывается по кнопке;
- «Подробнее» раскрывает технические вкладки Сессия / Печать / Глаза / Решение;
- глазной канал пока диагностический и не меняет итоговый уровень.

Демо-режим специально ускоряет временные пороги и не является проверкой реальной усталости.
