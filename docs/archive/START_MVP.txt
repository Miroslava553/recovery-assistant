АДАПТИВНЫЙ АССИСТЕНТ ВОССТАНОВЛЕНИЯ — ПЕРВАЯ СКВОЗНАЯ ВЕРСИЯ

1. Для быстрой проверки интерфейса и уведомлений:

   python assistant_app.py --demo

   В демо-режиме временные пороги ускорены:
   - короткая разгрузка примерно через 45 секунд работы;
   - микроперерыв примерно через 70 секунд;
   - более длинный перерыв примерно через 105 секунд.

2. Для реального режима:

   python assistant_app.py

3. Что уже влияет на решение:
   - контекст: работа / чтение / отсутствие / перерыв;
   - длительность непрерывной рабочей сессии;
   - устойчивая совокупность изменений печати после готовности личной нормы;
   - введённая пользователем самооценка.

4. Что пока НЕ влияет на решение:
   - моргания, PERCLOS и другие глазные показатели.

   Они показываются в интерфейсе только диагностически. Это сделано намеренно:
   глазной канал нельзя включать в решения до ручной разметки и отчёта о
   precision / recall.

5. Программа не хранит видео и не сохраняет введённый текст.
   Локально сохраняются только агрегаты, рекомендации и обратная связь.
