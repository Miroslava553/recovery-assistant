ПЕРВАЯ ПОЛЬЗОВАТЕЛЬСКАЯ ВЕРСИЯ ИНТЕРФЕЙСА

1. Демо интерфейса:
   python assistant_app.py --demo

   Важно: уведомление через 45 секунд — тест интерфейса.
   Оно НЕ означает, что программа обнаружила усталость.

2. Реальный режим:
   python assistant_app.py

   В реальном режиме первое уведомление по времени возможно только после 45 минут
   непрерывной работы. Глазной канал пока диагностический и в решения не входит.

Главный экран показывает только:
- камеру и состояние сигнала;
- текущий контекст;
- длительность непрерывной работы;
- одно понятное действие.

Технические показатели скрыты под кнопкой «Показать подробности».
Видео и введённый текст не сохраняются.
