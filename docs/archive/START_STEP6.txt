ЗАПУСК

1. Открой терминал в этой папке.
2. Для быстрой проверки выполни:

   python assistant_app.py --demo

3. Примерно через 45 секунд должно появиться отдельное всплывающее окно
   в правом нижнем углу экрана.
4. Камера в главном окне должна обновляться заметно плавнее, чем раз в секунду.

Рабочий режим без ускоренного таймера:

   python assistant_app.py

Проверка тестов:

   python -m unittest discover -s tests -v

Ожидаемый итог: Ran 108 tests, OK.
