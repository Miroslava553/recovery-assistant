# Изменение: персональная калибровка ракурса головы

Причина изменения: старая формула сравнивала каждого пользователя с одной
условной вертикальной пропорцией лица (`0.52`) и браковала нормальные кадры при
другой форме лица, высоте камеры или перспективе.

Теперь:

- первые секунды записи используются для оценки личной нейтральной позы;
- сохраняются только безразмерные отношения `head_turn_ratio` и
  `head_vertical_ratio`, их медианы и MAD;
- умеренные естественные движения не отбраковываются;
- сильные отклонения по-прежнему снижают качество и могут заблокировать кадр;
- команда `quality` умеет повторно оценить старую сессию без видео;
- отчёт сравнивает покрытие старой абсолютной формулы и новой персональной;
- если личную норму нельзя надёжно получить, статус становится
  `INSUFFICIENT_DATA`, а не ложным `PASS`.

Это исправляет контроль качества сигнала. Оно не доказывает точность детектора
морганий; precision/recall по-прежнему проверяются только после ручной разметки.
