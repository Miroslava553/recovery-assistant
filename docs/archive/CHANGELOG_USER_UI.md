# Пользовательский интерфейс MVP

- На главном экране удалены постоянные технические таблицы.
- Добавлено живое зеркальное изображение камеры без записи.
- Добавлен крупный явный баннер демо-режима.
- Демо-уведомления теперь прямо сообщают, что это тест интерфейса, а не обнаружение усталости.
- Убрано отдельное всплывающее окно рекомендации: действие показывается в одном основном окне.
- Технические показатели перенесены в скрываемый раздел «Подробности».
- Главный экран показывает один статус, одно объяснение и одно текущее действие.
